# Two-turn CAD example artifacts

All files are synthetic project examples, not private user designs.

| Artifact | Purpose |
|---|---|
| [create.json](create.json) | Typed edit for a 100 × 60 × 12 mm block with 10 mm corner setback; thickness and setback fixed |
| [widen.json](widen.json) | Adjust width by +20 mm, preserving the other dimensions |
| [created.reply.json](created.reply.json) | Actual Rust/host output: exact volume 71,400 mm³ |
| [widened.reply.json](widened.reply.json) | Actual output after edit: exact volume 85,800 mm³ |
| [demo.cad.json](demo.cad.json) | Editable v1 document including history/receipts; copy to a working directory and open using the CLI or viewer |
| [viewer.png](viewer.png) | Browser screenshot of the widened model generated by the Rust kernel |

The JSON commands are explicit accepted programs corresponding to the two natural-language instructions. They are not a claim of a recorded live model inference run. Reproduce them with the [quickstart](../../tools/ai-cad/README.md). Exact rational geometry is in the replies; float triangles exist only in the viewer. The saved snapshot uses a checksum envelope and should be changed through the host, not by hand.

License/ownership follows the repository; no public redistribution license for original source/artifacts has been selected. No third-party CAD data is included.
