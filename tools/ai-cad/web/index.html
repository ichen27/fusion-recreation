Supported geometry

Origin-aligned blocks and a 45° vertical cut at the +X/+Y corner. Cut size is its setback along each edge. Convex XY polygon profiles can be extruded in +Z. Profile coordinates and height reference editable parameters. Exact affine parameter relationships are supported. Convex extrusions support separate round through-holes in +Z. No blind holes, fillets or general sketch constraint solver yet. This is a bounded engine prototype.
